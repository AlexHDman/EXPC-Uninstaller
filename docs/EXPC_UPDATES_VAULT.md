## Реализовано

Сохранены быстрый registry reader, ленивый Store, удаление и адресные защиты BCU. Нет стартового сетевого/глубокого сканирования и Win32_Product. Одна верхняя строка, восемь кнопок; общие обработчики основного и контекстного меню. Контекстные цветные иконки 22 логических px; палитра и A/文 нарисованы векторно, без emoji. Остальные одобренные кнопки сохранены. Amber использует близкие нейтральные графитовые полосы, мягкие янтарные акценты; статусы сохраняют собственные цвета. EXPC-002 убран также из «О программе» на семи языках.

WinGet COM probe читает установленные идентификаторы и применимый установщик, проверки ограничены по времени. Сопоставление учитывает продукт, издателя, область, архитектуру, версию и ветку. Неоднозначные/неподтверждённые результаты не дают кольца. Optional Scoop/Chocolatey требуют явного выбора управляемого пакета и проверки совместимости конкретной версии/ОС. Установка выбранного пакета требует просмотра и подтверждения, повторно проверяет план и установленную версию. Очередь отменяется без уничтожения текущего установщика; перезагрузка автоматом не выполняется.

Сохранены собственные декларативные источники; добавлена привязка учётной записи к поддерживаемому адаптеру 1С. Произвольных команд в источниках нет. Мастер-хранилище использует PBKDF2-SHA256 (600000), соль 32 байта, AES-256-GCM, случайный nonce 12 байт, формат EXPCVLT1 и атомарную замену с зашифрованной резервной копией. Пароль/ключ не передаются в аргументах и не сохраняются открыто. Ручная блокировка отменяет защищённые запросы. Управляемые строки нельзя гарантированно стереть из памяти — это ограничение runtime, не обещание абсолютной очистки.

## Причины проблем и исправления

**Статусы.** В живом Sandbox воспроизведено: 7-Zip 25.01, найдено 26.04, но CanInstall=false/ManagerPinned. `winget pin list --disable-interactivity` завершался с -1978335162, поскольку обращался также к msstore с непринятыми соглашениями. Исправлено ограничением `--source winget`; получено exit 0 / «Закрепления не настроены». Соглашения Store не принимались, закрепления не обходились. Неизвестный/обрезанный ответ по-прежнему закрывает автоматическое обновление.

Дополнительно унифицированы модель текста, сортировка и отрисовка статуса: доступная веб-версия без стандартной установки отображается как ручная проверка. «Ещё не проверено» теперь отличается от «Источник неизвестен», подсказка использует время попытки при отсутствии успешной проверки. GUID с/без скобок сравниваются как GUID; на текущем компьютере это исправление не добавило соответствий, поэтому оно не объявляется причиной всех неизвестных статусов.

Проверка только менеджеров окончательной DLL: 380 записей, WinGet 1.29.380 / 89 пакетов; 20 Current, 18 Manual, 1 Update с правом стандартной установки, 341 Unknown. Это не означает, что 341 программа актуальна или что для них невозможно настроить отдельный источник. Этот отчёт не включает дальнейшую проверку веб-правил.

**Иконки.** Ранее использовался только DisplayIcon, маленький native handle и прямой путь Store, часто не соответствующий реальному scale/targetsize asset. Исправлены кавычки/индексы ресурсов, ICO/EXE/DLL, read-only MSI ProductIcon, явный executable деинсталлятора и варианты объявленного Store asset. Нет рекурсивного поиска; не более одного каталога для каждого объявленного asset. Извлечение после появления строк, два фоновых слота, кэш на запись, сброс только при обновлении. Native handles/Bitmap/файловые потоки освобождаются, запоздалый результат после refresh уничтожается. Недоступная/повреждённая иконка получает универсальную цветную пиктограмму, без чужого логотипа.

На реальном каталоге доступные оригиналы: обычные программы 147 → 165 из 380; Store 96 → 117 из 126. Сравнение direct/improved использует текущий загрузчик на DisplayIcon против всех разрешённых fallback; это не точное измерение старой сборки. Остальные оригиналы не найдены в разрешённых метаданных, глубокий поиск не выполнялся.
