## Что подключено

- Компактная таблица без сетки и рамок, полосы строк, цветные векторные кнопки и оригинальные значки программ. Основная гибкая ширина у названия; вспомогательные колонки сохраняются в логических пикселях. Заголовки учитывают перевод/DPI/значок сортировки, полные значения доступны в подсказках.
- Поиск, сортировка, обновление F5, переключение вкладок кнопками и Ctrl+Tab. Поиск снизу и одна строка состояния.
- Меню Файл / Действия / Вид / Справка. Действия и контекстное меню имеют общие обработчики и доступность: удаление / принудительное удаление / остатки / только запись; затем папка / реестр / официальный сайт / Google по названию и издателю; затем проверка выбранной версии / источник. Недоступность определяется выбранной записью, защитой и отсутствующими метаданными.
- Горячие клавиши: Ctrl+U, Ctrl+Shift+U, Ctrl+J, Ctrl+O, Ctrl+R, Ctrl+F5; Ctrl+F поиск, F5 обновление, Ctrl+Tab вкладки. Организация сверена с [официальным каталогом Geek](https://github.com/geekuninstaller/translations/blob/master/app/English.xml) и [сайтом Geek](https://geekuninstaller.com/). Это организация команд EXPC по проверенному источнику, не заявление о точном совпадении всех меню/горячих клавиш Geek.
- Проверка версий текущего отфильтрованного списка либо выбранного продукта. До проверки — неизвестное. Максимум три параллельных проверки, 22 секунды на продукт, отмена повторным нажатием кнопки, реальный счётчик. Чтение сети/разбор вынесены из UI. Нет загрузки полного списка в AI-сервисы и установки обновлений.
- Круглые статусы: не проверено, неизвестно, актуальна, есть обновление, ручная проверка, ошибка, отмена; прекращение поддержки только по явному правилу подтверждения. В текущих встроенных правилах подтверждённых end-of-support нет. По нажатию — версии, источник, обе даты, канал/ветка и ограничения совместимости.
- Декларативные VersionRules.json и индивидуальные sources.json: точные шаблоны имени/издателя, дополнительные ограничения ключа/архитектуры, источник, regex с группой version, канал, ветка, совместимость. Несколько подходящих правил дают неизвестное. Разные регистрации с похожим именем не объединяются. Архитектура any у источников с общей опубликованной версией не означает проверенную поддержку каждой архитектуры.
- Числовое сравнение сегментов версий; суффиксы и неоднозначное извлечение не угадываются. Другая ветка требует ручной проверки. Более новая установленная версия не предлагается к понижению. Новая публикация не подтверждает совместимость или обязательность обновления криптографического ПО.
- Редактор источника: официальный HTTPS URL / GitHub repo / необязательный WinGet / ручной источник; выражение, ветка, пробная проверка, сохранение и возврат к каталогу. Источники не содержат исполняемого кода. WinGet запускается только с точным ID, без установки и автоматического принятия соглашений.
- Темы Windows Light, Graphite, Glass Teal, Glass Blue, Glass Amber, Glass Ruby и «Как в Windows». Режим Windows читает и отслеживает настройку приложений Windows. Статусы сохраняют смысл цветов.
- ru/en/de/fr/es/it/pt: меню, собственные диалоги и подсказки; Windows language при первом запуске, иначе en. Имена продуктов, внешние деинсталляторы и системные исключения не переводятся EXPC.
- local-data рядом с EXE: settings.json, sources.json, versions.json, журналы и .reg backups. Атомарное сохранение с предыдущей копией .bak. Кэш привязан к установленной версии и правилу; ошибка/отмена сохраняет старую дату успешной проверки, отдельно записывая время попытки.
- Защиты удаления Phase 03, asInvoker, проверки регистрации/дочерних процессов, адресные остатки и резервные копии сохранены. В ядре менялись строки локализации; доказательства принадлежности остатков хранят стабильные ключи, чтобы смена языка не меняла идентичность кандидата.

## Воспроизведение сборки и тестов

Из корня репозитория, стабильный SDK 10.0.401:

```powershell
dotnet msbuild scripts/Build-ExpcPortable.proj -t:Package
dotnet msbuild scripts/Build-ExpcPortable.proj -t:Extract
dotnet test source/ExpcUninstallerTests/ExpcUninstallerTests.csproj -c Release -p:Platform=x64 -p:GenerateSatelliteAssembliesForCore=true
```

Если OutputRoot уже существует, упаковка намеренно откажет: задайте новый пустой путь параметром -p:OutputRoot=C:/AI/EXPC-Uninstaller/artifacts/completion/rebuild-01. Старые файлы не удаляются. Для сетевого отчёта: publish source/ExpcVerification/ExpcVerification.csproj с теми же RID/platform и запуск ExpcVerification.exe --network-report <локальный JSON>. Это отдельный стенд, не состав portable.

Для Sandbox: ExpcSandboxTests требует WDAGUtilityAccount и sentinel C:\EXPC-Test\ALLOW-SANDBOX-TESTS. Run-Phase03-Sandbox.cmd выполняет полный набор при входе в чистую VM. Run-Completion-Store.ps1 подписывает только заранее подготовленный собственный MSIX EXPC.SandboxFixture.Uninstall внутри Sandbox; сертификат не экспортирует с приватным ключом и не устанавливает на host. Входной пакет и MSIX manifest находятся в artifacts/completion/store-input, инструменты подписи — Windows SDK. -RunNonMsiSuite явно пропускает MSI; это отражается в console output. Полные команды/монтирования текущего опыта сохранены в локальных *.wsb артефактах.
