## Воспроизведение и причина

Через Computer Use открыт отдельный экземпляр текущего `artifacts/amber-height/portable/unpacked/EXPC-Uninstaller.exe`, меню Действия → Обновления. Пользовательский экземпляр с открытым редактором источника не изменялся.

В списке HDD Low Level Format 4.50 → 5.6 и Ollama 0.40.0 → 0.40.1 имели «Готово к обновлению», разрешённую checkbox-ячейку; Figma в текущем списке отсутствовала. Физический клик по HDD показал галочку, но accessibility Value оставалось False до перехода на другую ячейку; после перехода стало True. Поэтому утверждение «ни одна строка вообще не выбирается» полностью НЕ воспроизведено. Подтверждена отложенная фиксация редактируемой DataGridViewCheckBoxCell. Кнопка установки была активна и при нулевом выборе.

Код использовал стандартный отложенный edit lifecycle без немедленного commit/CellValueChanged и без связи Enabled кнопки с выбором. ItemCheck здесь неприменим: это DataGridView, не CheckedListBox. Привязки данных нет — значения хранятся непосредственно в строках. Также при сортировке grid индекс строки мог перестать соответствовать индексу entries, который использовала установка. Эта отдельная ошибка найдена по коду и покрыта регрессией; неправильная установка не запускалась.

## Исправление

- Checkbox переводится в явно управляемое редактирование: CellContentClick сразу переключает значение, без промежуточного грязного редактора. Space переключает checkbox текущей строки из любой её ячейки и не выполняется повторно стандартным обработчиком.
- CellValueChanged пересчитывает кнопку: активна только при допустимом выбранном пакете и отсутствии выполняемой операции. ReadOnly и CanInstall остаются обязательными; все проверки плана, идентичности, версии, совместимости и pins при установке сохранены.
- Row.Tag связывает строку с исходной записью; сортировка не меняет пакет, которому принадлежит выбор. После попытки установки обработанная строка остаётся недоступной; отмена очереди не уничтожает текущий установщик.
- Полные причина, совместимость и источник доступны в tooltip «Результат» и существующей нижней области подробностей. CurrentCellChanged обновляет сведения после смены текущей строки (SelectionChanged происходил раньше обновления CurrentRow).
- Тема, геометрия и состав функций сохранены. Значение checkbox не сбрасывается при перерисовке/resize.
