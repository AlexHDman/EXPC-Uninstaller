## Быстрое чтение и повторное использование BCU

- `FastCatalog.ReadRegistry()` читает только HKLM/HKCU `SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`, оба представления на x64, с read-only открытием ключей. Записи без имени пропускаются. Точный дубль определяется по имени ключа и прочитанным метаданным, включая версии/команды/путь/размер/дату/защитные признаки; совпадение одного DisplayName не объединяет программы.
- EstimatedSize в КБ преобразуется без переполнения; InstallDate принимается только как корректное `yyyyMMdd`. Неизвестные значения — `—`. Размеры каталогов не вычисляются.
- Иконки запрашиваются после первой отрисовки списка, только для видимых строк, максимум двумя параллельными задачами. Явный локальный путь на fixed drive; UNC, URL, относительные пути и ярлыки не разрешаются. При отсутствии доступной иконки остаётся нейтральная пиктограмма.
- Store загружается при первом переходе через неизменённый `StoreAppHelper.AppManager.QueryApps()` BCU. Запрос текущего пользователя, PackageTypes.Main. Оболочка не запускает helper EXE и не вызывает `UninstallApp`. Чтение манифестов/PRI выполняется только после выбора Store. Повторный переход использует кэш в памяти, обновление перечитывает его.
- Для безопасного владения извлечённой native-иконкой используется `Klocman.Tools.DrawingTools.CreateOwnedIconFromHandle`.
- Нет зависимости оболочки от `UninstallTools`, глубокого обнаружения BCU, `Win32_Product`, поиска остатков, сканирования папок, проверки подписей или сетевого запроса. Перечисление выполняется на worker-задаче, UI только применяет результат. Это быстрый reader, а не перенос глубокого pipeline в фон.
- Манифест оболочки `asInvoker`: чтение не требует запроса администратора. Манифесты и проверки опасных действий BCU сохранены без изменений.

## Ограничения и сохранность

- Список registry-записей включает зарегистрированные компоненты SDK/системные записи; это не тот же набор, что глубокое обнаружение BCU. Незарегистрированные portable-программы не ищутся. Другие пользовательские профили не обходятся.
- Store helper BCU пропускает отключённые/недоступные пакеты и пакеты с нечитаемым манифестом. Он не сообщает число пропусков оболочке, поэтому `errors: 0` для Store не доказывает полноту. Размер и дата в его модели отсутствуют; показаны `—`. Версия берётся из FullName пакета. Системные main-пакеты также видны.
- Runtime ZIP, выпуск через Actions, другие архитектуры, Windows 10, слабые ПК, DPI 150%, проверка версий и удаление здесь не аттестованы. Реально собран и запущен x64.
- `Licence.txt`, `NOTICE`, авторство BCU / Marcin Szeniak и существующие уведомления не изменены. Licence/NOTICE копируются к новому EXE. Метаданные версии пока унаследованы от исходной базы BCU 6.3; EXPC-002 обозначает дизайн, не выпуск BCU.
- Пользовательские `assets/icon.ico` и `assets/UI_Master_Visual.png` добавляются в Git без изменений, чтобы сборка и эталон были воспроизводимы. Их SHA256 соответственно `3FC0D66BEB7F1CDB05E4D825BBFD9938F79291AA142D86C83618317FB0D1B6A4` и `938967CC4A513F0C0F2462690C397297B238892CE621AC800FD018541A9C048E`.
- Пользовательский `desktop.ini` не изменён и не включён в commit. Настройки, реальные списки, логи, кэш, EXE и снимки не включаются. Push/release не выполняются.
