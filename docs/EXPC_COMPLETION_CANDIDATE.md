# EXPC: кандидат удаления и обновлений — 2026-10-09

STATUS: код и self-contained portable собраны; 126/126 фоновых тестов пройдены. Пользовательская GUI-приёмка — NOT TESTED. База 9302a46a, ветка expc/updates-vault.

## Сделано

- Штатное удаление из панели, меню и контекстного меню сохраняет единый маршрут RunSelected → StandardRemoval: одно короткое тематическое подтверждение, отмена по умолчанию; затем только статус главного окна. Повторный запуск защищён. Внешний деинсталлятор и UAC не подавляются, тихий режим не добавлен.
- До запуска сохраняются отдельные копии регистрации, версии, издателя, команд, InstallLocation, источников (hive/view), MSI ProductCode и достоверно связанных путей данных. Registry32/64 — сведения о представлении регистрации, а не обещание точно установленной архитектуры бинарника. Команды сохраняются только в локальном диагностическом журнале; его нельзя публиковать без проверки содержимого.
- Основное ожидание использует события WMI и Toolhelp, отслеживает потомков и период покоя. При недоступном WMI резервное автоматическое подтверждение ограничено MSI: проверенный msiexec/ProductCode, успешный exit code, завершение наблюдаемых процессов, стабильное отсутствие регистрации и MsiQueryProductState=UNKNOWN. Для произвольного EXE отсутствие записи и выход родителя успехом не объявляются.
- Для unconfirmed / прекращённого наблюдения в главном окне доступно «Проверить остатки…»: сначала пользователь подтверждает окончание внешнего деинсталлятора, затем только поиск/просмотр. Известные живые PID с проверкой времени старта блокируют очистку. Через 30 минут прекращается наблюдение, установщик не завершается принудительно.
- После подтверждённого удаления результат показывается и при пустом поиске; ошибка/неполные метаданные не превращаются в «Остатков не найдено». Адресный поиск не сканирует диски. Он использует подтверждённый каталог, точный ключ продукта с InstallLocation и явно записанные UserDataPath/DataPath/ProfilePath текущего пользователя. Общие папки издателя исключены. Полнота для любого приложения не обещается.
- В реестре добавлены отдельные вложенные ключи и значения. Они остаются пользовательскими данными и не отмечаются автоматически. Исключённые потомки блокируют родителя в плане; новые значения/ключи препятствуют удалению ключа. Значения перепроверяются по хешу содержимого; перед изменением сохраняется .reg. Якорь InstallLocation удаляется только вместе с полностью разрешённым корневым ключом. Проверяются registry links и файловые reparse points. Журнал остаётся внутри формы, очистка отображения не стирает диагностику/backup.
- В обновлениях checkbox больше не зависит от CanInstall. Выбор мышью/Space применим к ручным и заблокированным строкам. Стабильный идентификатор учитывает запись, область/представление реестра и путь установки, не версию и не отображаемое название. Сортировка/перестроение сохраняют выбор.
- Подключены редактор источника и перепроверка в том же окне, игнорирование/возврат, показ игнорируемых и открытие страницы загрузки. Игнорирование сохраняется в local-data/ignored-updates.json. Новый ключ регистрации после переустановки считается новой установкой: похожие записи автоматически не объединяются.
- Установка показывает число разрешённых/недоступных выбранных строк и причины. Драйверы исключены из обычного пакетного обновления. Идентичность, совместимость, закрепления и защита portable → installed сохранены. Сайт без сопоставленного пакета не считается механизмом установки.
- Общая отрисовка градиентных звёзд: серый — не проверено/игнорируется с подписью; синий — новая версия; зелёный — подтверждённая актуальность; жёлтый — действие/неопределённость; красный — ошибка. Проверка явно подписана. Зелёное кольцо удалено; смысловые цвета не зависят от темы.
- Усилены Ruby, Blue, Teal и тёмная Windows; Amber сохраняет базовую палитру. Windows Light сохраняет прежнюю палитру. Собственные заголовки/поддерживаемые scrollbar используют оформление Windows API; оригинальные иконки приложений не перекрашиваются. «О программе» показывает реальную assembly version 6.3.0.0, описание, BCU/лицензии и компактную центральную кнопку.

## Установленные причины

Figma: журнал прежнего direct-removal за 2026-10-08 содержит unconfirmed при Available=false; StandardRemoval выходил до поиска. Конкретное исключение для Figma не сохранено. В более новом журнале confirmed-removal от 2026-10-08 22:14:03 UTC WMI Start возвращает Access denied, но это другая операция (КриптоПро), завершившаяся отменой 1602; её нельзя называть успешным удалением или доказательством той же ошибки у Figma.

Рутокен: сохранённый кэш confirmed-removal от 2026-10-09 01:14 МСК содержит две отдельные записи драйверов 5.0.01.0000 / 5.0.1.0 → 5.3.0.0 и плагин 4.11.2.0 → 4.13.0.0. State=Update, Reason=ComparedBranch, Compatibility=RutokenWindows, Package=null. Источник — сайт; подтверждённого пакета для автоматической установки нет. Ранее это также запрещало checkbox. Теперь выбор разрешён, а установка ограничена с конкретным пояснением; драйвер требует отдельного решения пользователя.
