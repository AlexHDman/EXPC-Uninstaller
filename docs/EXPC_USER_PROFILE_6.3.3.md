# EXPC 6.3.3 — пользовательские данные и закрытие

Дата: 2026-10-28. Локальный кандидат, без commit/push/tag/release. База ddb0fd6b, ветка codex/release-6.3.1; ранее внесённые незакоммиченные изменения сохранены.

## Сделано
- Все постоянные данные EXPC направлены в `%LOCALAPPDATA%\EXPC\Uninstaller\Data`: local-data, настройки, источники, vault, обязательный журнал операций и registry-backups.
- Legacy origin используется только для чтения и самообновления исходного EXE. Режим записи пользовательских данных рядом с EXE удалён. Удалены стартовая проверка записи рядом с EXE и обработка desktop.ini в приложении.
- При первом запуске копируются старые local-data и accounts.expc-vault* из папки запущенного EXE. Хеши копий проверяются; оригиналы не удаляются, существующие назначения не перезаписываются. Reparse-пути отклоняются. Завершённый импорт отмечается в Data. Реальные данные пользователя агент не переносил и не открывал.
- NotifyIcon и команды трея удалены. Крестик, Alt+F4 и Выход завершают приложение; lifetime/version-check отменяются, vault блокируется. Открытое, но не выполняющее операцию окно остатков больше не блокирует выход. При активном удалении/очистке/установке закрытие блокируется предупреждением; внешние процессы не завершаются принудительно.
- Cache/Logs сохраняют правила предыдущего кандидата: кэш в Uninstaller/Cache, диагностика в Uninstaller/Logs и метрики выключены по умолчанию.
- Временная копия и backup самообновления теперь создаются в пользовательском staging, не рядом с EXE. Для исходного EXE на другом томе автоматическая атомарная замена отклоняется до изменения файла; нужна ручная замена. Это ограничение введено ради требования не создавать соседние служебные файлы.

## Приёмка
Сначала завершить старый экземпляр через Файл → Выход, затем вручную запустить новый EXE. Старые папки local-data/метрики рядом со старым EXE сохраняются как оригиналы; приложение не удаляет их автоматически. Новый импорт читает папку именно запущенного EXE, не ищет данные по всему диску. При запуске из другой папки старые данные не ищутся автоматически на рабочем столе.

После выполнения: активное пользовательское тестирование; функциональная разработка на паузе. Опубликованные release/tag 6.3.1 не изменялись. Итоговый GUI агент не запускал.
