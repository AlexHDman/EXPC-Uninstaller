# EXPC-Uninstaller — требования продукта

Дата фиксации: 2026-10-06. Статус: **EXPC-002 утверждён**, рабочая оболочка Phase 02 реализована. Визуальный эталон: `assets/UI_Master_Visual.png`. Результаты Phase 02 — `EXPC_PHASE02.md`; переход на .NET 10 и portable — `EXPC_PHASE02A.md`.

## Цель и границы Phase 01

Portable-деинсталлятор на основе Bulk Crap Uninstaller (BCU), с простотой Geek Uninstaller, собственным интерфейсом EXPC и проверкой актуальности установленных программ.

Phase 01 завершён: исходники, сборка, запуск BCU и baseline сохранены в commit `2362764a`. Phase 02: отдельная оболочка EXPC с реальным быстрым списком, без подключения удаления и проверки версий. Ядро и старый интерфейс BCU не переделываются. На рабочем компьютере не выполнять удаление приложений, остатков или записей реестра.

## Главное окно

- Быстрый запуск; простой список без перегруженных панелей и мастеров.
- Компактное вертикальное окно с изменяемыми размерами; небольшие шрифты и плотные строки.
- Колонки, в указанном порядке: **Программа / Размер / Установлено / Версия / Статус / Новая**. Последние четыре обозначают дату установки, установленную версию, актуальность и доступную версию соответственно.
- Верхнее меню: **Файл / Действия / Вид / Справка**.
- Под меню маленькие кнопки **только с иконками**: удалить, обновить список, проверить версии. Названия — в подсказках.
- Справа маленькие кнопки темы и языка, затем две иконки-вкладки: **Программы / Microsoft Store**.
- Поиск находится внизу; ниже — компактная строка состояния.
- При последующем подключении темы и язык открывают список сразу, без вложенной навигации. В Phase 02 эти кнопки явно отключены и снабжены подсказками.
- Никаких дополнительных панелей, мастеров, карточек, массовых операций и функций вне согласованного этапа.
- Контекстное меню: удаление; принудительное удаление; поиск остатков; удаление записи; папка программы; запись реестра; официальный сайт; Google; указание источника обновлений.
- Подтверждения простые и относятся к конкретному действию. Существующие защитные проверки BCU, включая проверки в UI-слое, не отключать.

## Оформление

- Стеклянные кнопки с лёгким объёмом, тонким бликом и мягкой подсветкой.
- Контрастный текст и спокойная таблица.
- Темы: **Windows Light, Graphite, Glass Teal, Glass Blue, Glass Amber, Glass Ruby**.
- Основная тема: **Glass Teal**. Дополнительный режим: **Как в Windows**.
- Статусы: простые маленькие круглые значки по EXPC-002. До проверки — только неизвестный статус `?` с пояснением и `—` в колонке «Новая». Демонстрационные программы и версии из эталона не используются. По подключении проверок нажатие показывает пояснение и источник; смысл статуса не зависит от темы.
- Предусмотреть собственную иконку EXPC и оформление папки через `desktop.ini`.
- Используется предоставленная пользователем `assets/icon.ico`; эталон PNG не является иконкой. Иконка, эталон и существующий `desktop.ini` сохраняются без изменения содержимого. Оформление папки не реализуется в Phase 02.

## Локализация

Русский, английский, немецкий, французский, испанский, итальянский и португальский. Автоматически выбирать язык Windows, при отсутствии поддерживаемого языка — английский. Ручной выбор сохраняется рядом с EXE. Наличие старых переводов BCU не означает готовность переводов новых строк EXPC.

Граница Phase 02: русская Glass Teal. Строки и цвета вынесены из логики окна в `UiText` и `GlassTeal`; автолокализация и переключатели будут подключены отдельно.

## Быстрый список — обязательное изменение EXPC-002

- **Глубокое стартовое сканирование BCU отменено.** Оно не вызывается ни синхронно, ни в фоне.
- Обычные программы: чтение зарегистрированных uninstall-записей HKLM/HKCU в 32/64-bit представлениях, устранение точных дублей метаданных. Одного совпадения названия недостаточно для объединения.
- На старте запрещены обход дисков/папок, поиск остатков, вычисление размеров каталогов, проверка подписей, сетевые проверки и `Win32_Product`.
- Размер и дата берутся только из метаданных. Отсутствующие или некорректные значения показываются как `—`.
- Иконки загружаются лениво для видимых строк, после появления списка. Только явные локальные пути; без сетевого разрешения и поиска файлов.
- Microsoft Store запрашивается при первом выборе вкладки, для текущего пользователя. Возврат использует кэш в памяти. «Обновить список» перечитывает только текущий источник.
- UI остаётся отзывчивым. Время появления окна и заполнения списка измеряется отдельно; выводы ограничиваются проверенной машиной.
- Поиск остатков допускается только для выбранной программы после удаления либо по отдельной команде пользователя. В Phase 02 эта команда отключена.
- В Phase 02 реально работают список, поиск, сортировка, обновление и обе вкладки. Удаление, зачистка, изменение записей, проверка версий и другие неподключённые действия отключены; фиктивных результатов нет.

## Актуальность программ

- Источники: **WinGet, официальные сайты, GitHub Releases**.
- Пользователь может сохранить собственный источник и правило извлечения версии.
- Раздельно учитывать последнюю опубликованную версию и совместимость с текущей Windows. Новейшая версия может быть несовместима.
- Неизвестный результат не объявлять актуальным. Отсутствие релизов не считать доказательством закрытия проекта.
- Сохранять время и источник проверки. По нажатию на статус показывать основания результата.
- Фоновая проверка не блокирует интерфейс.
- Проверка актуальности не подразумевает автоматическую установку обновлений: такая функция не утверждена.
- Конкретные значки, правила сопоставления программ, формат пользовательских правил, обработку ошибок и семантику сравнения версий подтвердить отдельным POC. Не выдавать предположение за проверенный результат.

## Portable, сборка и платформы

- Portable ZIP включает runtime: распаковал и запустил без установки зависимостей. В Phase 02A собран win-x64 с .NET 10.0.12; SDK строго 10.0.401 (`global.json`, preview запрещён), trimming выключен.
- Настройки, источники и кэш находятся рядом с EXE. Локальные настройки, инвентаризация, логи и кэш не коммитятся.
- Исходники доступны; сборка должна быть воспроизводимой. Portable-релизы через GitHub Actions — последующий этап.
- Приоритет: Windows 10/11, включая старые ПК. Реальную поддержку архитектур определяют исходники, сборка и запуск на соответствующей системе.
- Наличие конфигурации AnyCPU/x86/x64/ARM64 не равно проверенной поддержке. Минимальную версию Windows, запуск без установленного .NET, время старта и потребление памяти проверять отдельно.
- Сохранить `Licence.txt`, `NOTICE`, авторство BCU и уведомления встроенных компонентов. Не представлять EXPC как официальный релиз BCU.

## Минимальное направление реализации

Решение Phase 02 заменяет предварительное направление Phase 01: отдельный проект `source/ExpcUninstaller`, C# / WinForms / .NET 10 (с Phase 02A), запускаемый `EXPC-Uninstaller.exe`. Быстрый registry reader принадлежит оболочке. Из BCU повторно используются только подходящие helpers: `StoreAppHelper.AppManager.QueryApps()` и `Klocman.Tools.DrawingTools.CreateOwnedIconFromHandle`. Зависимости от старой главной формы и `UninstallTools` у стартового списка нет. Общий рефакторинг BCU не выполняется.

До будущего подключения опасных действий сохранить цепочку защит текущих `AppUninstaller`, `MainWindow`, мастера запуска удаления и окна остатков. Быстрая модель списка пока не является входом для удаления: безопасный адаптер к механизмам BCU потребует отдельной проверки. Проверку версий добавлять отдельно от удаления.

## Порядок дальнейшей работы

Один согласованный практический шаг → тест → отчёт → STOP. После Phase 02 пользователь проверяет запущенное окно EXPC. Подключение удаления, проверки версий, остальных тем/языков и GitHub Actions требует следующего отдельного задания.
